# 🚀 Quick Start - One Command

## Easiest Way to Start

```bash
./start.sh
```

That's it! This will:
- ✅ Start Docker (DB + Redis)  
- ✅ Seed the database
- ✅ Run API + Frontend concurrently

## Alternative Commands

```bash
# Start everything
npm start

# Just run dev servers (Docker must be running)
npm run dev

# Stop everything
npm run stop
```

## Service URLs

- **Frontend**: http://localhost:3000
- **Backend**: http://localhost:4000
- **Health Check**: http://localhost:4000/health
